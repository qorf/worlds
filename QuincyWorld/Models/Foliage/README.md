# Foliage models

RockA.glb, RockB.glb and RockC.glb come from Terrain3D's demo
(project/demo/assets/models), under Terrain3D's MIT license
(LICENSE-Terrain3D). The originals have no material; these copies add one
gray stone material (base color 0.42, 0.40, 0.37, roughness 0.9) so they
don't draw white. Nothing else was changed.
